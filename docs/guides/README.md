# Grama · developer docs

Grama is a Spanish word game: drag across letters on a wheel to find the words of each
level. It's a static PWA (Svelte 5 + TypeScript) with no server: levels are generated on
the device from shipped word lists.

These pages explain how it's built, for anyone reading or changing the code.

- **[How it works](./how-it-works.md)**: the big picture, then three walkthroughs
  through the code.
- **[Words](./words.md)**: where the word lists come from and how the game uses
  them.
- **[Difficulty](./difficulty.md)**: how levels are scored, classified, paced
  and kept from repeating.
- **[Working on it](./working-on-it.md)**: commands, workflow and standards.
- The game's rules ([GAME](../GAME.md)), the decision log
  ([DECISIONS](../DECISIONS.md)) and the roadmap ([PLAN](../PLAN.md)).
- The **API reference**: every module, in the menu, grouped by folder.

For players there's [Todo sobre Grama](https://ewajs.github.io/grama/guia/), in Spanish.
