## Estrellas

Cada nivel completo te da de 1 a 3 estrellas:

|     | Cómo                                       |
| --- | ------------------------------------------ |
| ★★★ | Sin pistas y con al menos 3 palabras extra |
| ★★  | Con una pista como mucho                   |
| ★   | Completándolo                              |

Si volvés a jugar un nivel, queda tu mejor resultado.

## El mapa

El mapa muestra todos los niveles a los que llegaste, con su dificultad (el color de
arriba) y sus estrellas. El nivel actual está resaltado.

Tocá cualquier nivel anterior para **volver a jugarlo**, por ejemplo para conseguir las 3
estrellas. Es exactamente el mismo nivel; los puntos y las pistas cuentan igual, pero tu
nivel actual no cambia.

## Logros

Los logros se desbloquean solos mientras jugás; te avisamos con un cartelito arriba.
Están todos en la pantalla **Logros**, con lo que te falta para cada uno, junto con tus
estadísticas.

| Logro               | Cómo se consigue                           |
| ------------------- | ------------------------------------------ |
| Primer paso         | Completá tu primer nivel                   |
| Desafiado           | Completá un desafío del día                |
| Arrancando          | Completá 10 niveles                        |
| Racha               | Completá el desafío 3 días seguidos        |
| Tres estrellas      | Ganá 3 estrellas en un nivel               |
| Cien palabras       | Encontrá 100 palabras del tablero          |
| Sin miedo           | Completá un nivel extra difícil            |
| Por mi cuenta       | Completá 10 niveles sin pistas             |
| Curioso             | Encontrá 50 palabras extra                 |
| Constante           | Completá 50 niveles                        |
| A pulmón            | Completá un nivel extra difícil sin pistas |
| Estrellado          | Ganá 3 estrellas en 10 niveles             |
| Cielo lleno         | Juntá 100 estrellas                        |
| Semana redonda      | Completá el desafío 7 días seguidos        |
| Duro de roer        | Completá 10 niveles extra difíciles        |
| Cien de cien        | Completá 100 niveles                       |
| Diccionario andante | Encontrá 1000 palabras del tablero         |
| Explorador          | Encontrá 500 palabras extra                |
| Imparable           | Completá el desafío 30 días seguidos       |
