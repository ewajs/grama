# Dificultad

Los niveles no se ponen difíciles de a poco y para siempre: van **alternando**, para que
haya desafíos y respiros. Cada nivel tiene una de cuatro dificultades, que ves debajo del
número de nivel.

## Qué hace difícil a un nivel

No es la cantidad de letras (eso crece con tu [progreso](/niveles#los-niveles-crecen)),
sino **qué palabras hay en el tablero**:

- **Qué tan comunes son.** `CASA` es más fácil de ver que `TÁNDEM`.
- **Qué tan largas son.** Las palabras largas cuestan más.
- **Cuántas son.** Los niveles difíciles piden más palabras: en la rueda de 8 letras, un
  fácil pide hasta 7 y un extra difícil hasta 10.

Cada nivel recibe un puntaje según esas dos cosas, y ese puntaje lo pone en una de las
cuatro dificultades: **fácil**, **media**, **difícil** o **extra difícil**. Para armar un
nivel de cierta dificultad, el juego elige sus palabras de un grupo más o menos amplio
del diccionario, y verifica que el resultado tenga la dificultad buscada.

## El ritmo

Las dificultades siguen un ciclo de 7 niveles que se repite:

| 1     | 2     | 3     | 4       | 5     | 6     | 7                 |
| ----- | ----- | ----- | ------- | ----- | ----- | ----------------- |
| Fácil | Media | Media | Difícil | Fácil | Media | **Extra difícil** |

- Después de un extra difícil, siempre viene uno fácil.
- No hay extra difíciles antes del nivel 15: primero te soltás.
- Desde el nivel 50, el fácil del medio del ciclo pasa a ser medio.

## Más difícil, más premio

| Dificultad    | Puntos   | Además                                                         |
| ------------- | -------- | -------------------------------------------------------------- |
| Fácil y media | normales |                                                                |
| Difícil       | ×1,5     |                                                                |
| Extra difícil | ×2       | una [pista](/pistas) de regalo la primera vez que lo completás |

## Elegí tu dificultad

En el menú del juego, **Dificultad** te deja elegir cómo querés jugar. Se aplica desde el
próximo nivel.

|                | Qué cambia                                                      |
| -------------- | --------------------------------------------------------------- |
| **Relajada**   | Cada nivel es un escalón más fácil, y nunca hay extra difíciles |
| **Normal**     | El ritmo de arriba                                              |
| **Desafiante** | Cada nivel es un escalón más difícil                            |

El [desafío del día](/desafio-del-dia) tiene su propia dificultad, igual para todos.
